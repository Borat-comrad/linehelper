# LineHelper — полный набор сценариев тестирования организационного контура

**Версия источника:** 2025-12-17  
**Количество сценариев:** 360  
**Диагностических групп:** 18

## Назначение

Пакет предназначен для прогона полного контура: вопрос → retrieval → контекст → локальная модель → ответ → протоколирование → заключение.

## Поля протокола

`id`, `group_id`, `question`, `retrieval_query`, `top_results`, `context`, `answer`, `search_time`, `generation_time`, `status`, `failure_type`, `comment`.

Статусы: `PASS`, `PARTIAL`, `FAIL`, `MANUAL_REVIEW`. Приоритеты: `P0` — критическая фактическая ошибка; `P1` — неверная маршрутизация; `P2` — неполнота/качество.

## Общие критерии

- Не выдумывать сотрудников, должности, контакты и статусы.
- Вакансии не представлять как занятые.
- Неактивные органы не представлять как действующие.
- При маршрутизации указывать непосредственного ответственного и рабочий контакт.
- При неоднозначности запрашивать уточнение.
- Указывать версию 2025-12-17, когда вопрос касается актуальности.
